PERCEPTIONTESTS — FIRST START

1. Extract the complete ZIP archive to a writable folder.
2. Do not run the application from inside the ZIP.
3. Keep all files in the extracted folder together.
4. Read docs\CALIBRATION.md before participant data collection.
5. Start the application with START_PERCEPTIONTESTS.bat. In the single-file package, PerceptionTests.exe can also be started directly.
6. Complete a validation run and confirm that JSON files are created.
7. Archive the application version and both configuration files used by the study.
